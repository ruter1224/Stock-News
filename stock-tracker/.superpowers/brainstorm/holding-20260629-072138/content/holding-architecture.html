持倉初始化功能設計 (holding)

新增 holding add / holding list / holding remove 三個子命令

系統架構流程圖
CLI Layer (main.py)
holding add
holding list
holding remove
▼ 呼叫下層
Portfolio Layer (portfolio.py)
add_init_holding(stock, shares, cost, config)
→ 檢查是否已存在該股票（若存在則拒絕）
→ 呼叫 calculator 建立 init state
▼ 傳遞
Calculator Layer (calculator.py)
init_holding(state, tx, config)
→ 新 action 類型 "init"
→ 設定 shares = tx.shares, total_cost = tx.total_amount
→ avg_cost = total_cost / shares
→ 無手續費 / 無交易稅
▼ 儲存
Data Layer (store.py / state.json)
Portfolio → JSON → 寫入 state.json
與現有 buy/sell/dividend 完全相容儲存

使用範例

# 首次使用：直接設定目前持倉
$ python main.py holding add --stock 2330 --shares 2000 --cost 500000
→ 平均成本：250.00，已記錄初始持倉
# 查看狀態
$ python main.py status
# 後續正常買賣
$ python main.py add buy --stock 2330 --date 2026-06-01 --price 300 --shares 500
# 產生含即時股價的報表
$ python main.py report --stock 2330 --auto-price
