一、簡介

Stock Tracker 是一款專為台灣股票投資人設計的交易紀錄管理工具，幫助您追蹤持股成本、計算損益、管理股利，並提供歷史回測功能。

主要功能

  • 📈 持股管理 — 記錄買入、賣出、股利等交易
  • 💰 成本計算 — 自動計算均價、總成本、零成本狀態
  • 📊 即時股價 — 自動抓取 Yahoo 股市即時報價
  • 📉 歷史回測 — 分析投資組合歷史表現
  • 📥 CSV 匯入匯出 — 支援券商交易明細匯入
  • 🔄 再投資對沖 — 股利再投資自動降低持有成本
  • 🥧 圓餅圖 — 視覺化持股分佈

系統需求

項目需求
作業系統Windows 10 / 11 (64-bit)
瀏覽器Chrome / Edge / Firefox (最新版)
硬碟空間約 50 MB
網路需要（抓取股價用）

二、安裝與啟動

步驟 1：取得程式

將 StockTracker.exe 複製到您想要存放的資料夾，例如：

C:\Programs\StockTracker\StockTracker.exe

步驟 2：首次啟動

1 雙擊 StockTracker.exe
2 會開啟一個黑色命令列視窗，顯示：
================================================== Stock Tracker - 股票交易帳本 ================================================== 資料目錄: C:\Programs\StockTracker\data 正在啟動伺服器 (port 5000)... 瀏覽器將自動開啟 http://127.0.0.1:5000 關閉此視窗即可停止伺服器 --------------------------------------------------
3 瀏覽器會自動開啟，顯示 Stock Tracker 介面
程式會在 exe 同目錄下自動建立 data 資料夾，存放您的交易資料。請不要刪除這個資料夾。

步驟 3：停止程式

直接關閉黑色命令列視窗即可。

請勿直接關閉瀏覽器來停止程式，應該關閉命令列視窗。否則伺服器會持續在背景執行。

五、個股管理

在此頁面可以新增個股、記錄交易、查看歷史。

新增個股

1 點擊 📅 新增個股 按鈕
2 在彈出視窗中填寫：
  • 股票代碼：例如 2330
  • 股數：持有股數（張 × 1000）
  • 總成本：含手續費的總金額
  • 日期：買入日期
3 點擊「確定」完成新增

記錄交易

選擇股票後，可以進行以下操作：

+ 買入 - 賣出 $ 現金股利 ~ 股票股利 ↻ 再投資

買入操作

填寫日期、價格、股數，以及手續費（或總支出）。

賣出操作

填寫日期、價格、股數，以及手續費和交易稅（或總收入）。

模式切換：買入/賣出對話框可以切換「明細模式」和「總額模式」。
• 明細模式：分別填寫手續費、交易稅
• 總額模式：直接填寫總支出或總收入

現金股利

填寫日期和股利總額（每股股利 × 股數）。

股票股利

填寫日期和增加的股數。

股利再投資

將股利再投資買入同一檔股票，填寫日期、價格、股數。

再投資對沖機制：再投資時，系統會依據設定模式計算成本：
• 模式 A（直接扣成本）：再投資金額直接從總成本扣除，均價隨之下降
• 模式 B（需有股利才能扣）：再投資金額最多扣到已收現金股利總額，超過部分當一般買入
• 如果沒有現金股利記錄，系統會自動備註「無對應股利記錄」

交易歷史

每筆交易都會記錄詳細資訊，最新加入的「備註」欄位會顯示再投資對沖狀態。

六、ETF 管理

ETF 管理與個股管理操作方式相同，差別在於：

  • ETF 的交易稅率較低（預設 0.1%）
  • 系統會自動識別 ETF（代號為 00 開頭）

七、回測分析

回測功能可以分析您的投資組合在歷史上的表現。

使用步驟

1 切換到「📈 回測」分頁
2 選擇回測標的：
  • 整體投資組合：分析所有持股
  • 單一股票：分析特定股票
3 選擇回測期間：1 年 / 3 年 / 5 年 / 10 年
4 點擊「🔄 執行回測」
首次執行回測前，需要先點擊「📥 下載歷史股價」來取得歷史資料。

八、設定

費率設定

手續費率0.001425 (0.1425%)
個股交易稅 (上市)0.003 (0.3%)
個股交易稅 (上櫃)0.003 (0.3%)

儲存 恢復預設
修改費率後，只有「新交易」會使用新費率。已存在的交易紀錄不會重新計算。

再投資模式

在設定頁面可以選擇股利再投資時的成本計算方式：

模式 A：直接扣成本所有再投資金額直接從總成本扣除，不管有沒有收過股利。如果沒有股利記錄，會自動備註「無對應股利記錄」
模式 B：需有股利才能扣再投資金額最多扣到已收現金股利總額，超過部分當一般買入計入成本

範例說明

持有 1,000 股，成本 50,000 元（均價 50.00）

操作模式 A 結果模式 B 結果
① 收到股利 12,000 元 成本 50,000（不變），已收股利 +12,000 同左
② 再投資 12,000 元（200 股） 成本 50,000 - 12,000 = 38,000
均價 38,000 / 1,200 = 31.67		 同左
③ 再投資 15,000 元（超額，無股利） 成本 50,000 - 15,000 = 35,000
備註：無對應股利記錄		 可扣 12,000，超額 3,000 計入
成本 50,000 - 12,000 + 3,000 = 41,000

股價快取管理

點擊「清除快取」可以清除所有股價快取，下次更新股價時會重新抓取。

九、常見問題

Q：開啟程式後瀏覽器沒有自動開啟？

請手動開啟瀏覽器，前往 http://127.0.0.1:5000

Q：顯示「網路錯誤」或股價無法更新？

請檢查網路連線。程式需要連線到 Yahoo 股市抓取股價。如果網路正常但仍無法更新，可能是 Yahoo API 暫時無法使用，請稍後再試。

Q：如何備份我的資料？

您的交易資料存放在 data 資料夾中。定期複製整個 data 資料夾即可備份。也可以使用「匯出 CSV」功能匯出交易紀錄。

Q：如何在另一台電腦使用？
  1. 複製 StockTracker.exe 到新電腦
  2. 複製 data 資料夾到同目錄下（如果要保留舊資料）
  3. 雙擊 exe 即可使用
Q：程式佔用多少記憶體？

正常運作時約佔用 50-100 MB 記憶體。關閉命令列視窗後會完全釋放。

Q：可以同時開啟多個視窗嗎？

可以開啟多個瀏覽器分頁，但建議只使用一個。多個程式實例可能會造成資料衝突。

Q：Port 5000 已被佔用怎麼辦？

目前版本固定使用 Port 5000。如果該 Port 已被其他程式使用，請先關閉該程式，或聯繫開發者支援自訂 Port。

Q：如何完全移除程式？
  1. 關閉命令列視窗
  2. 刪除 StockTracker.exe
  3. 刪除 data 資料夾（如果不需要保留資料）
